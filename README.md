# 🌌 Inf

> Un pequeño proyecto personal para aprender cómo funciona la recopilación de información disponible desde un navegador utilizando JavaScript y Firebase.

## 📖 Sobre el proyecto

**Inf** nació como un experimento. Mi objetivo era entender qué información puede obtener un navegador de forma pública, cómo almacenarla en Firebase y cómo organizar un proyecto web moderno utilizando HTML, CSS y JavaScript.

Este proyecto no busca ser una herramienta comercial. Es simplemente una forma de aprender, practicar y experimentar con distintas APIs que ofrecen los navegadores.

Cada parte fue construida poco a poco, investigando documentación, haciendo pruebas y corrigiendo errores hasta conseguir el resultado que quería.

---

## ✨ Características

- Registro automático de visitas.
- Integración con Firebase Realtime Database.
- Detección de información del navegador.
- Información del dispositivo.
- Información de la pantalla.
- Datos básicos de la red.
- Información de la batería (cuando el navegador lo permite).
- Información de la GPU mediante WebGL.
- Geolocalización aproximada usando la IP.
- Tiempo activo e inactivo durante la visita.
- Interfaz moderna con animaciones.

## 🚀 Objetivo

Más que crear una página bonita, quería comprender cómo interactúan los navegadores con diferentes APIs y cómo organizar un proyecto completo utilizando Firebase.

Fue una buena oportunidad para practicar programación, depuración de errores y despliegue en GitHub Pages.

---

## ⚠️ Nota

La información recopilada depende de los permisos y limitaciones del navegador utilizado. Algunas APIs pueden no estar disponibles en todos los dispositivos.
